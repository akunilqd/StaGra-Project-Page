# MRI Segmentation via Training-Free Statistical-Graph Framework

Project page for the paper **MRI Segmentation via Training-Free Statistical-Graph Framework**.

## Local preview

From this directory, run:

```powershell
python -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.

## Contents

- `index.html` - project page
- `assets/mri-segmentation-stagra.pdf` - paper PDF
- `assets/brats2021-results/` - BraTS 2021 qualitative results
- `assets/styles/stagra-paper.css` - page styles
- `assets/scripts/stagra-paper.js` - navigation and citation interactions
